# ヤニブ オンライン

ヤニブ（オリジナルルール）を3〜5人で、各自の端末から遊べるWebアプリの試作です。ルールは [RULES.md](RULES.md)。

## 動かし方

Node.js 18 以上が必要です（追加パッケージなし）。

```
node server.js
```

http://localhost:3000 を開き、1人が部屋を作って、部屋番号かリンクを他の人に送ります。

## ファイル

- `server.js` … サーバー（部屋の管理と通信）
- `game.js` … ゲームの進行と点数計算
- `public/index.html` … 各プレイヤーの画面
- `local.html` … 1台の端末を回して遊ぶ版（サーバー不要）

## 制限

- 部屋はサーバーのメモリにだけあり、再起動すると消えます
- 途中参加はできません
