# ヤニブ オンライン

ヤニブ（オリジナルルール）を3〜5人で、各自の端末から遊べるWebアプリの試作です。ルールは [RULES.md](RULES.md)。

## 遊び方（GitHub Pages 版）

公開ページを開き、1人が部屋を作って、部屋番号かリンクを他の人に送ります。

- 部屋を作った人のブラウザがゲームを管理し、他の人はブラウザ同士で直接つながります（WebRTC / PeerJS）
- 部屋を作った人は、遊び終わるまでページを開いたままにしてください
- 再読み込みしても、同じ端末・同じブラウザなら続きから戻れます

## ファイル

- `index.html` … GitHub Pages 版の画面（サーバー不要）
- `game.js` … ゲームの進行と点数計算（両方の版で共通）
- `local.html` … 1台の端末を回して遊ぶ版（サーバー不要）
- `server.js` / `public/index.html` … Node.js サーバー版（`node server.js` → http://localhost:3000）
